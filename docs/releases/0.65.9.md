# Origami 0.65.9

- Menu « Profil et réglages » (PS3, 360) : la sortie ne reste plus bloquée par un menu fantôme.
- Tsuru : l'écran du haut passe sous la barre d'état (coins du haut droits) et la manette sous la barre de navigation ; les barres montrent le fond de chaque thème.
- Formats d'image : l'image reste au centre, seul le rapport change.
- PS3 Performance : agrandissement bilinéaire (SGSR retiré, jamais testé sur le Fold).
- Journaux : mesures de performance toutes les 5 s (charge, mémoire, fréquence de chaque cœur, GPU, températures).
