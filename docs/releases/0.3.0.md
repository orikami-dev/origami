## 🚀 Origami 0.3.0

### Ce qu'elle apporte

emblème de console original sur fond transparent (plus de cartouche en vedette), croix directionnelle complète (◀ ▶ jeu sans boucler, ▲ ▼ console), boutons A/B/X/Y en losange aux couleurs neutres, SELECT (favoris/tous), START (lancer), bouton maison (1 appui : options d'émulation, 2 appuis : retour au Flex), ligne d'état qui affiche chaque appui.

📲 Installation : télécharge l'APK ci-dessous et installe-le par-dessus la version précédente (tes réglages sont conservés).
