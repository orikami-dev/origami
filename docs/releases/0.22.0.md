## 🚀 Origami 0.22.0

### Ce qu'elle apporte

console « Arcade » (cœur fbneo), reconnue par le dossier (arcade/, fbneo/, neogeo/, mame/, cps1-3/) ; jaquettes « FBNeo - Arcade Games », ScreenScraper 75. PS1 en HD : CoreManager.UPGRADES lance swanstation (OpenGL, échelle 3× par défaut via DEFAULT_OPTIONS) quand un BIOS PS1 est dans system/, sinon pcsx_rearmed. .pbp tranché par PARAM.SFO (CATEGORY ME = PS1, sinon PSP). 0.22.1 : ATH de monitoring (img/s, vitesse, CPU de l'app, mémoire, batterie/température, état thermique) dans Réglages > Affichage et le menu pause ; NetherSX2/AetherSX2 lancés avec l'URI SAF du document (ClipData + ACTION_MAIN, comme ES-DE) au lieu du chemin /storage qui les faisait planter. 0.22.2 : le bouton dossier de la barre devient « Actualiser la bibliothèque » (ic_refresh, toast avec le nombre de jeux) ; le dossier se choisit dans Réglages > Bibliothèque. 0.22.3 : jaquettes ScreenScraper (box-2D, région fr > eu > wor > us) en secours de libretro-thumbnails, qui n'a pas de Switch : recherche par nom de fichier puis par titre nettoyé ; compte ScreenScraper requis.
