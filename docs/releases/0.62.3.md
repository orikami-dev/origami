# Origami 0.62.3

- Gâchettes en vrais haricots, comme les touches de la manette GameCube : bandes incurvées côte à côte, sans dépasser du bord (Xbox 360 comprise).
- Format d'image et Accélérer ×2 deviennent de petites icônes rondes dans les coins du haut ; sauvegarde et chargement rapides restent sous Maison.
- Assistant : la musique du thème démarre dès qu'on le choisit ; sous-titre « Options audio ».
- Sonar animé : plus de ligne fixe, seuls le balayage et des échos rouges qui clignotent.
- Éditeur de manette allégé, sans défilement horizontal ; choix de la console pour la Flex ; « Disposition d'origine » remet le modèle exact de chaque manette.
