## 🔧 Origami 0.50.1

### Ce qu'elle apporte

lancement des jeux PS3 (à tester par BOSS).
- Moteur PS3 intégré : cœur ARMSX3 (RPCS3 pour Android, GPL-2.0-only, commit 103fc79e) compilé dans le cloud avec le NDK r29 (variante Snapdragon 8 Gen 1 et plus : armv8.2-a+dotprod+fp16, API 33), 100 Mo une fois allégé. Correctifs de compilation dans native/armsx3-patches/01-linux-build.patch.
- Lancer un jeu PS3 (image .iso ou dossier avec PS3_GAME) ouvre Ps3Activity dans son propre processus « :ps3 » avec son journal (logcat-ps3.txt). Premier lancement : Origami demande le firmware officiel PS3UPDAT.PUP (à télécharger sur le site de PlayStation), puis l'accès à tous les fichiers. Aussi dans Réglages > BIOS et sauvegardes > Importer le firmware PS3.
- Manette Origami vers la manette PS3 par position (A = Croix, B = Rond, X = Carré, Y = Triangle), manettes physiques comprises ; menu Maison : reprendre, sauvegarde et chargement rapides, menu PS du jeu, quitter.
- APK de 64 Mo (le moteur PS3 pèse l'essentiel). Version publique : le moteur sera un téléchargement à part (module à la demande sur le Play Store).
- Préparation Xbox 360 (0.60) : console reconnue (images .iso XGD, .xex, .zar, dossiers avec default.xex), emblème, X360Activity et pilote de manette « origami » pour Xenia. Le moteur n'est pas encore dans l'APK.
