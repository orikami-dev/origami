## 🚀 Origami 0.15.0

### Ce qu'elle apporte

disposition par défaut refaite par BOSS (grille 43 × 28 : L2/L1 et R2/R1 empilés, SAVE/SELECT, Maison, Accélérer, LOAD/START en haut au centre, croix et losange en bas), une seule pour tous les écrans (plus de variante compacte). Menus codec sur toute la pilule du haut, carte translucide, deux colonnes si la place le permet (croix : ▲▼ par ligne, ◀▶ par entrée). Éditeur par catégories (Touches, Disposition, Fond, Couleurs, Vibrations) ; roue de couleurs (ColorWheelView : teinte/saturation + luminosité) avec teintes prêtes à droite, pour la manette, les touches, l'accent ou une touche ; vibration réglable (coupée/légère/moyenne/forte, via le vibreur : permission VIBRATE).
