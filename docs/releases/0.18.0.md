## 🚀 Origami 0.18.0

- Vrais onglets dans l'éditeur (barre fixe soulignée, seule la page défile).
- Option « Interface aux mêmes couleurs » : l'interface prend les couleurs de la manette.
- Manettes physiques jusqu'à 4 joueurs, avec mappage automatique (touches Android standard, manettes Nintendo, sticks, croix analogique, gâchettes).
- Réglages > Manettes : joueur, disposition Nintendo, zone morte, assistant de réattribution, retour à l'automatique.
- Plein écran dès qu'une manette est branchée (option, activée par défaut).
- Menu codec adapté à la manette : carte centrée et aide aux touches.
