## 🚀 Origami 0.35.0

### Ce qu'elle apporte

retouche de la manette sur le jeu (Options contrôleur → « Modifier la manette ici » : jeu en pause, barre Ajouter / Retirer / − / + / ⇅ / Annuler / Terminer ; ControlDeckView.pinHere fige la disposition affichée sur la grille courante, puis plus aucun réarrangement). Une disposition par zone : Store.screenLayout / setScreenLayout (pref slayout_<cols>x<rows>), rechargée à chaque changement d'écran, d'orientation ou de mode (ControlDeckView.followScreen / reloadFromSource) ; « Revenir à la disposition commune ». Superposée sur écran large sans retouche : ControlLayout.wideOverlay (une colonne par pouce contre chaque bord : gâchettes, croix ou boutons, joystick ; Select-Maison-Start en haut au centre ; échelle réduite seulement si la hauteur manque). Marge de sécurité 8 dp + encoche (GameActivity.safeArea). VIT des cœurs à fil propre (ARMSX2) mesurée au son émulé : un jeu PAL à 25 images/s affiche 100 %. Démarrage : OrigamiSplash, la grue pliée en deux s'ouvre sur son pli, lève les ailes puis vient vers l'utilisateur (≈ 1,9 s, appui pour passer, immobile si les animations sont coupées) ; en bas seulement « ORIGAMI » et le studio « KAMI-WORKS ».
