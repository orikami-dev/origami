## 🚀 Origami 0.4.0

### Ce qu'elle apporte

lancement sans le sélecteur Android générique (détection des émulateurs installés qui savent ouvrir la console, une seule fenêtre si plusieurs, choix mémorisé), jaquette du jeu en vedette (emblème de la console sinon), récupération automatique des jaquettes depuis libretro-thumbnails (désactivable dans le menu maison).
