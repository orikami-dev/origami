## 🚀 Origami 0.26.0

### Ce qu'elle apporte

menu Maison « Options contrôleur » (au lieu de « Modifier la manette ») : manette tactile (éditeur, mode paysage superposé ou séparé, transparence 10 à 70 %), plein écran avec manette, boutons rapides, puis une entrée par manette physique (joueur, disposition Nintendo, page de test et de réattribution). Avec une manette physique en plein écran, les pastilles SAVE / LOAD / ×2 restent en haut à droite (Store.padQuickButtons). Écran externe : rotation libre (Theme.orientation toujours UNSPECIFIED). Paysage à plat : manette superposée et transparente par défaut (Store.landscapeDeck « overlay », overlayOpacity 35 %), ou séparée. Page Manettes : la manette testée ne pilote plus l'app (rond/B/Retour ne ferment plus la page ; Select + Start pour quitter) ; PadView redessiné d'après les modèles officiels (manette PS5 bicolore avec pavé tactile, Xbox avec lettres de couleur, Pro Switch avec − + maison et capture), toujours sans logo. Mode débogage (Réglages > À propos) : DebugLog copie le logcat de l'app dans files/logs (2 × 2 Mo), écrit les plantages, « Partager le journal » avec une fiche de l'appareil ; le pont laisse passer les messages DEBUG des cœurs seulement dans ce mode (Libretro.nativeSetDebug).
