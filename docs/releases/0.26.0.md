## 🚀 Origami 0.26.0

- Menu Maison « Options contrôleur » : manette tactile (éditeur, paysage superposé ou séparé, transparence 10 à 70 %), plein écran avec manette, boutons rapides, une entrée par manette physique (joueur, disposition Nintendo, test et réattribution).
- Avec une manette physique en plein écran, les pastilles SAVE / LOAD / ×2 restent en haut à droite.
- Écran externe : rotation libre.
- Paysage à plat : manette superposée et transparente par défaut, ou séparée.
- Page Manettes : la manette testée ne pilote plus l'app (Select + Start pour quitter) ; manettes redessinées d'après les modèles officiels (PS5, Xbox, Pro Switch), sans logo.
- Mode débogage (Réglages > À propos) : journal des plantages, « Partager le journal » avec une fiche de l'appareil.
