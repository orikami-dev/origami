## 🚀 Origami 0.10.0

### Ce qu'elle apporte

menu Maison en jeu enrichi. Format d'affichage par console (origine, 4:3, 16:9, étiré, pixels entiers ; image lissée ou pixels nets). Options avancées du cœur (toutes celles que le cœur déclare, mémorisées par cœur, appliquées à chaud quand le cœur le permet). Codes de triche par jeu (Action Replay, GameShark, Game Genie, CodeBreaker selon le cœur ; une partie par ligne), enregistrés dans saves/<jeu>.cheats.json et réappliqués à chaque lancement.

📲 Installation : télécharge l'APK ci-dessous et installe-le par-dessus la version précédente (tes réglages sont conservés).
