## 🚀 Origami 0.1.0

### Ce qu'elle apporte

premier build de FOLD/PLAY. Lanceur rétro adaptatif au Galaxy Fold (écran externe, ouvert à plat, mode Flex à moitié plié via le capteur de charnière), bibliothèque par dossier pour 13 consoles, lancement de RetroArch avec le bon cœur, favoris et récents, navigation à la manette. Aucun émulateur, jeu ni BIOS inclus.

📲 Installation : télécharge l'APK ci-dessous et installe-le par-dessus la version précédente (tes réglages sont conservés).
