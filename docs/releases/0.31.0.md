## 🚀 Origami 0.31.0

### Ce qu'elle apporte

script d'installation des cœurs (assets/cores/install.json lu par CoreInstaller), lancé tout seul après chaque téléchargement (en jeu ou depuis Réglages) et à la demande (« Relancer l'installation ») : vérification ELF arm64, fichiers d'appoint, puis profil de réglages selon la gamme de l'appareil (haut : SM8xxx, Dimensity 9xxx, Tensor ou 12 Go+ ; milieu : 8 Go+ ; bas) pour SwanStation, PPSSPP, Mupen64Plus-Next et Flycast. Le profil (Store.coreProfile) est appliqué avant les choix de l'utilisateur, qui gardent la main. Page du cœur : note d'installation, choix de version (CoreCatalog.VARIANTS : Nestopia/Mesen, Snes9x 2010, SameBoy, gpSP/VBA Next, PicoDrive, DeSmuME, YabaSanshiro, ParaLLEl N64, MAME 2003-Plus ; la version choisie se télécharge sous le nom du cœur, ses réglages repartent de zéro) et retour à la version précédente (gardée en .prev à chaque mise à jour). Clés du profil non vérifiées sur appareil : une clé inconnue est ignorée par le cœur.

---
📲 Installation : télécharge l'APK ci-dessous et installe-le par-dessus la version précédente (tes réglages sont conservés).
