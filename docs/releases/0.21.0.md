## 🚀 Origami 0.21.0

### Ce qu'elle apporte

la 3D. Le pont natif accepte SET_HW_RENDER (OpenGL ES 2/3, pas de GL de bureau ni de Vulkan) : contexte EGL hors écran (pbuffer) créé sur le fil d'émulation après retro_load_game, framebuffer maison (texture RGBA8 + profondeur/stencil) qui grandit si le cœur relève sa résolution, glReadPixels retourné vers le tampon Java (même affichage que les cœurs logiciels). libEGL/libGLESv3 ouverts par dlopen. Test sur la machine : native/test/run-gl.sh (Mesa surfaceless). Cœurs intégrés ajoutés : N64 (mupen64plus_next_gles3), PSP (ppsspp, avec PPSSPP.zip des assets libretro dans system/), Dreamcast (flycast, BIOS facultatif). N64 : A/B par nom, Z sur L2, C gauche/haut/droite/bas sur X/Y/R2/Select, L/R sur L/R, croix = stick analogique si la disposition n'a pas de joystick. Classique refaite par BOSS : Maison 6×6 (aussi sur Flex, 0.20.3), croix rentrée, A B X Y en 5×5. 0.21.1 : Réglages > Émulateurs > « Retélécharger les cœurs » (un ou tous, CoreManager.redownload) ; éditeur : redimensionner seulement par le coin d'une touche déjà choisie (coin ≤ 35 % de la touche), touches carrées suivant la diagonale du geste (avant, déplacer Select/Save les faisait grossir) ; .pbp reconnu comme PSP. 0.21.2 : sur N64/PSP/DC le joystick n'envoie plus la croix (Midnight Club : la croix tournait la caméra) ; manette en surimpression cachée tant qu'un menu est ouvert (GameActivity.deckUnderMenu).
