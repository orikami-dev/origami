## 🚀 Origami 0.7.0

### Ce qu'elle apporte

manette du bas entièrement configurable. Icône manette (à gauche de l'engrenage) : éditeur sur la vraie moitié basse, avec grille grise de 16 dp où les touches s'aimantent ; déplacer en glissant, redimensionner par le coin vert, le pincement ou les boutons − / + ; ajouter n'importe quelle touche (croix, A/B/X/Y, L/R, L2/R2, Select, Start, Maison) ou en supprimer ; plusieurs dispositions enregistrées (nouvelle, renommer, dupliquer, réinitialiser, supprimer), celle surlignée est l'active ; image de fond copiée dans l'app, déplaçable et zoomable. L'engrenage ouvre directement la page Réglages, onglets agrandis. L2/R2 sautent de cinq jeux.

📲 Installation : télécharge l'APK ci-dessous et installe-le par-dessus la version précédente (tes réglages sont conservés).
