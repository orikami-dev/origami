## 🚀 Origami 0.7.0

- Manette du bas entièrement configurable : éditeur sur la moitié basse, grille aimantée, déplacement par glissement, redimensionnement (coin vert, pincement, boutons − / +).
- Ajout ou suppression de n'importe quelle touche (croix, A/B/X/Y, L/R, L2/R2, Select, Start, Maison).
- Plusieurs dispositions enregistrées (nouvelle, renommer, dupliquer, réinitialiser, supprimer).
- Image de fond de la manette, déplaçable et zoomable.
- L'engrenage ouvre directement les Réglages, onglets agrandis ; L2/R2 sautent de cinq jeux.
