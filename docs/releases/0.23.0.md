## ⭐ Mise à jour majeure : Origami 0.23.0

- PS2 intégrée : ARMSX2 livré dans l'APK, rendu OpenGL ES 3.2.
- Import de BIOS PS2 depuis Réglages > Émulateurs > « Importer un BIOS » ; un BIOS posé dans le dossier système est rangé tout seul.
- NetherSX2 reste proposé à côté.
- ATH refait façon RTSS : une ligne en haut de l'écran, temps d'image moyen et pic.
- Réglages ATH dans Affichage : style ligne/bloc, position, taille, couleur des libellés, bandeau sombre, rythme et mesures au choix (images/s, temps d'image, vitesse, CPU, mémoire, batterie, température, chauffe, moteur et résolution, heure).
- Mention de licence GPL et lien vers le code source d'ARMSX2 dans À propos.
