## ⭐ Mise à jour majeure : Origami 0.23.0

> **PS2 intégrée (ARMSX2).**

### Ce qu'elle apporte

PS2 intégrée. ARMSX2 (fork ARM64 de PCSX2, GPL-3.0) compilé en cœur libretro Android avec le NDK r29 (native/build-armsx2.sh, commit 25e7084), livré dans l'APK (lib/arm64-v8a/libarmsx2_libretro.so, prebuilt/armsx2/) : CoreManager.BUNDLED, jamais téléchargé ; ressources (shaders, GameIndex, polices) dans assets/pcsx2-resources.zip, recopiées dans system/pcsx2/resources à chaque nouvelle version. Rendu OpenGL ES 3.2 par le pont existant (le cœur capture le contexte EGL du fil d'émulation et dessine depuis son fil GS dans un contexte partagé). BIOS PS2 dans system/pcsx2/bios : Réglages > Émulateurs > « Importer un BIOS » (sélecteur Android, tri par taille : 4/8 Mo = PS2, 512 Ko = PS1) ; un BIOS PS2 posé dans system/ est rangé tout seul. NetherSX2 reste proposé à côté. Pont natif compilé avec le vrai NDK (repli sur les souches sans NDK). ATH refait façon RTSS (Hud.java) : une ligne en haut de l'écran, libellés orange, valeurs blanches, unités plus petites, temps d'image moyen et pic ; réglages dans Réglages > Affichage : style ligne/bloc, position (gauche/centre/droite), taille, couleur des libellés (orange RTSS, vert Codec, blanc), bandeau sombre, rythme (0,5/1/2 s) et mesures au choix (img/s, temps d'image, vitesse, CPU, fréquence CPU, mémoire, batterie, température, chauffe, moteur et résolution, heure). Mention GPL et lien vers le code source d'ARMSX2 dans À propos.
